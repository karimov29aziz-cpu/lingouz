# Lingo

Сайт для изучения языков: карточки, тесты, словарь, прогресс и универсальный ИИ-ассистент Nexus-Core.

## Запуск

1. Установите Node.js 22.13 или новее: https://nodejs.org
2. Откройте папку в терминале VS Code (Terminal → New Terminal).
3. Выполните: `node server.js`
4. Откройте http://localhost:3000

Пакеты ставить не нужно. Рядом с `server.js` появится файл базы данных `lingo.db`
(SQLite). Прогресс, который уже был в браузере, перенесётся в базу сам.

## Уровень английского

На главной странице (и в тренажёре) выберите уровень от A1 до C1. Сайт подбирает слова вашего
уровня и одного уровня ниже: на A1 это 30 самых простых слов, на C1 слова уровней B2 и C1
(например, *meticulous*, *mitigate*, *scrutinise*). Всего в английском 150 слов, по 30 на уровень.
Когда вы выучите 80% слов своего уровня, тренажёр предложит перейти на следующий. Уровни есть
только у английского, у остальных языков пока базовые слова.

## Nexus-Core — ИИ-ассистент

Раздел «Nexus-Core» — универсальный чат для вопросов, помощи с кодом и проектами, редактирования
текстов, объяснений и разработки промптов для генераторов изображений. При запросе на создание
изображения ассистент выдаёт визуальную концепцию и готовый промпт на английском языке; генерация
самого изображения не подключена. Ответы формирует выбранная модель ИИ, подключение которой
настраивается ниже.

## Уроки (сборка предложений из блоков)

Раздел «Уроки» работает по принципу курсов, где фразу по-русски нужно собрать по-английски из блоков со словами.
Это 16 уроков по 8 предложений, от `to be` до `Present Perfect`. В начале каждого урока короткая подсказка по грамматике.
Нажимайте на блоки по порядку, затем «Проверить». Ошибочное предложение возвращается в конец урока, пока вы не соберёте всё верно.
С 5-го урока среди блоков появляются лишние слова. После верного ответа предложение озвучивается.
Лучший результат каждого урока сохраняется (в базе данных, если запущен `server.js`).

## Предложения из блоков в тренажёре

В тренажёре есть режим «Предложения»: по русскому предложению нужно собрать перевод из блоков со словами.
Нажмите на блок, чтобы поставить его в ответ, и ещё раз на него в ответе, чтобы вернуть назад. Среди блоков
есть лишние слова. В английском их число растёт с уровнем (1 на A1, до 3 на B2 и C1), а сами предложения
берутся из вашего уровня и одного ниже (по 10 на каждый уровень A1–C1). У остальных языков по 6 простых предложений.
Предложения, которые вы собрали верно три раза подряд, считаются выученными и видны на странице «Прогресс».

## Подключение ИИ-модели

Вне Claude чату нужен источник модели. Выберите один вариант и впишите его в файл `.env`
(скопируйте `.env.example` в `.env`), потом **перезапустите сервер**.

**1. Ollama: бесплатно, без ключей, всё на вашем компьютере**

1. Установите Ollama: https://ollama.com и запустите её.
2. В терминале: `ollama pull llama3.2`
3. Перезапустите `node server.js`

Нужно около 3 ГБ места и 8 ГБ памяти. Если у вас уже скачана другая модель, сайт возьмёт её сам.
Для лучшего качества попробуйте `qwen2.5:7b` и укажите `OLLAMA_MODEL=qwen2.5:7b`.

**2. Бесплатный облачный сервис (например, Groq): ключ без банковской карты**

1. Зарегистрируйтесь на https://console.groq.com и создайте API-ключ.
2. В `.env` впишите:
   ```
   AI_PROVIDER=openai
   OPENAI_BASE_URL=https://api.groq.com/openai/v1
   OPENAI_API_KEY=ваш_ключ
   OPENAI_MODEL=llama-3.3-70b-versatile
   ```
   Название модели берите из списка моделей в консоли сервиса: оно может измениться.
3. Так же подключаются и другие сервисы, совместимые с OpenAI (OpenRouter, Google Gemini и др.):
   меняются только адрес, ключ и модель.

**3. Claude через Anthropic API: лучшее качество, платно**

```
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-...
```

Ключ хранится только на сервере и в браузер не попадает.

### Если чат не работает

Откройте страницу «Nexus-Core»: она сама покажет причину и кнопку «Проверить снова».
Типичные причины:

- Сайт открыт не по адресу http://localhost:3000 (двойной щелчок по `index.html` или Live Server не подходят).
- Сервер запущен давно и работает со старым кодом или старым `.env`. Остановите его (Ctrl+C в терминале)
  и запустите снова: `node server.js`.
- Ollama не запущена или модель не скачана.
- В `.env` пустой или неверный ключ.

Когда чат подключится, кнопка «Проверить подключение» в боковой панели сделает пробный запрос.

## Таблицы базы данных

- `progress`: уровень каждого слова (0–5)
- `custom_words`: ваши слова
- `activity`: количество упражнений по дням
- `settings`: выбранный язык, серия дней
